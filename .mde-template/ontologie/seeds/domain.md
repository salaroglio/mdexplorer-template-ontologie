# The domain

## TL;DR

This document says what the ontology models, where it ends and which documents it starts from. Every agent of the
method reads it. **It is to be filled in**: as long as it says «to be filled in», the analyst agent stops and asks for it.

- One sentence on the domain, then what is inside and what is outside.
- The list of documents: the agents read those and only those.
- The prefix and the base address of the ontology, the same in every file.
