# L'esempio

Questa cartella c'è solo nel ramo `esempio`: i file iniziali compilati per un'ontologia della gara di Nordica Crediti
(dati inventati, dalla demo di MdExplorer): dominio, fonte, domande di competenza, schema, regole, istanze, query e il rapporto
di verifica. Chi crea un progetto «con l'esempio» li riceve in `ontology/` al posto dei modelli vuoti.
