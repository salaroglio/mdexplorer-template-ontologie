## Ontologie

- `ontology/` è l'ontologia del gruppo: dominio, domande di competenza, schema, regole, esempi, query e verifica.
  Quando ti chiedono dell'ontologia, parti da `ontology/domande.md`: dice a che cosa serve.
- Il giro è il workflow `.mde-template/ontologie/workflows/ontologia.md`: non far partire tu i suoi agenti e non scrivere
  i loro file al loro posto.
- Per sapere se un file Turtle si legge, se i dati rispettano le regole o che cosa risponde una query, usa lo strumento
  `rdf_check`: non indovinare.
- I file in `.mde-template/ontologie/` sono del metodo e arrivano con i suoi aggiornamenti: non modificarli.
